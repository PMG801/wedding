# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/) como código de conducta.

## Nuestro compromiso

Queremos que participar en el proyecto sea una experiencia libre de acoso para todas las personas, sea cual sea su edad, tamaño corporal, discapacidad, etnia, identidad o expresión de género, nivel de experiencia, nacionalidad, apariencia, raza, religión u orientación sexual.

## Comportamiento esperado

- Trato respetuoso y empático.
- Críticas constructivas, centradas en el código y no en las personas.
- Aceptar con elegancia las revisiones y los desacuerdos técnicos.

## Comportamiento inaceptable

- Acoso, insultos, comentarios despectivos o ataques personales.
- Lenguaje o imágenes sexualizados.
- Publicar información privada de otras personas sin su permiso.
- Cualquier conducta que se considere razonablemente inapropiada en un entorno profesional.

## Aplicación

Las personas mantenedoras pueden editar o eliminar comentarios, commits, issues y otras contribuciones que no se ajusten a este código, y vetar temporal o permanentemente a quien lo incumpla.

Para informar de un problema de conducta, escribe en privado a la persona mantenedora a través de su perfil de GitHub ([@PMG801](https://github.com/PMG801)). Todas las quejas se revisarán con discreción.

Texto completo y guía de aplicación: <https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/>.
