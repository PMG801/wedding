## Contract (story carousel, binding for T2/T3/T6)
- **Capture time** is a local wall-clock string `YYYY-MM-DDTHH:MM:SS` (no zone). The client extracts it before upload: JPEG/HEIC EXIF `DateTimeOriginal` (fallback EXIF `DateTimeDigitized`), MP4/MOV `mvhd` creation time (UTC, converted with the device time zone; 0/1904 epoch = absent). Never `File.lastModified`.
- **Upload**: `PUT /api/media/{id}` accepts optional header `X-Captured-At: YYYY-MM-DDTHH:MM:SS`. Missing, malformed or impossible values (year outside 2000-2100, invalid date) are ignored: the upload proceeds and stores NULL (a photo is never lost for its metadata). An idempotent retry of a confirmed id never changes the stored value.
- **Storage**: migration `0004` adds nullable `media.captured_at TEXT` (CHECK on the shape) and partial index on `(captured_at, id)` for visible media with a capture time.
- **Config**: `BODA_PERIOD_<n>_START` / `BODA_PERIOD_<n>_END`, n = 1, 2, … consecutive, value `YYYY-MM-DDTHH:MM` in event local time, START < END, half-open `[START, END)`. A lone START/END, a bad value, START ≥ END or a gap in n fails startup naming the variable. No periods = feature off (API returns empty list). `BODA_CAROUSEL_SIZE` (default 10, 1..50), `BODA_CAROUSEL_ROTATION` (Go duration, default `30m`, ≥ 1m).
- **`GET /api/carousels`** (guest session): `{"rotates_at":<unix ms of next slot>,"periods":[{"id":n,"start":"…","end":"…","total":<media in period>,"items":[<gallery item>…]}]}`. Only periods with ≥ 1 visible medium. Items: up to SIZE, chosen by a deterministic shuffle seeded by (period id, slot = floor(now / rotation)), identical for every guest within a slot, returned in capture-time order. Item shape = `GET /api/media` item. `Cache-Control: no-store`.
- **`GET /api/carousels/{id}?cursor=&limit=`** (guest session): full album, visible media of the period ordered by `captured_at, id` ascending, keyset cursor, `limit` 1..100 (default 50), page shape = `GET /api/media`. Unknown id → 404 `{"error":"period_not_found"}`; errors otherwise as the gallery (`invalid_limit`, `invalid_cursor`).
- **UI**: a compact strip of round bubbles (one per period, label = time range, e.g. «18:00–20:00») at the top of the guest home; tapping opens a story viewer over that period's items (tap/swipe to advance, close returns); from it «Ver álbum completo» opens the album section `#/album/<id>`, loaded as a lazy chunk. Strip refetches at `rotates_at`. Budget S12 (mobile-ui-polish, now 40 KB gzip): strip + extraction must stay ≤ 2.5 KB gzip; album section outside the entry chunk.
