## Specs
Source: read-only audit of the MVP against the Oracle Always Free A1 host (2 vCPU ARM64, 12 GB RAM, shared 200 GB volume), approved by the user (L1). Each spec quotes the approved audit item.

- **S1 — Disk reservation.** Audit: "El umbral de espacio libre no reserva lo que ya está en curso ... Solución: llevar en memoria la suma de los tamaños declarados en curso y restarla del espacio libre." Photo, video and derivative uploads share one in-process ledger: an upload is accepted only when `free - reserved - declared >= BODA_DISK_MIN_FREE_BYTES`; the reservation is released when the upload finishes or fails. Rejection keeps `507 insufficient_storage` and leaves no stored data.
- **S2 — Derivative bounds.** Audit: "Los `tmp/*.staged` de miniaturas cuyo original nunca se confirma no se borran nunca" and "El límite de miniaturas es de 50 MB, cuando con 1–2 MB bastaría." Staged derivatives whose original is not confirmed are deleted by reconciliation after `BODA_STAGED_DERIVATIVE_TTL` (default 24h). Derivatives use their own limit `BODA_MAX_DERIVATIVE_BYTES` (default 8 MiB), rejected with `413 derivative_too_large` before reading the body.
- **S3 — Server and SQLite hardening.** Audit: "`http.Server` no define `IdleTimeout`", "`GOMEMLIMIT` no está definido; `512MiB` sería una red de seguridad barata", "`synchronous(NORMAL)` contradice lo que promete el runbook ... Hay que poner `FULL` o documentar el compromiso en un ADR". Server gets `IdleTimeout` 120s and `MaxHeaderBytes` 64 KiB; no `ReadTimeout`/`WriteTimeout`. SQLite uses `synchronous(FULL)` and `journal_size_limit`. Container sets `GOMEMLIMIT=512MiB`.
- **S4 — Admin upload switch (ADR-0008).** Audit: "No existe el interruptor de administración del ADR-0008 ... no se pueden cortar las subidas manualmente desde el móvil (T7 y T9)." Admin login with `BODA_ADMIN_PASSWORD_HASH`, separate `SameSite=Strict` session cookie, progressive delay after failures; `GET /api/admin/status` (manual switch, automatic disk pause, free/reserved bytes); `POST /api/admin/settings` toggles `uploads_enabled` in SQLite `settings`. While paused, `PUT /api/media/{id}` and derivatives return `503 uploads_paused`; reads keep working. Minimal mobile admin page at `/admin` (Spanish UI).
- **S5 — SQLite backup.** Audit: "No hay copia de seguridad de SQLite. El ADR-0003 describe un `VACUUM INTO` nocturno, pero no está implementado." A periodic job writes `VACUUM INTO` to `backup/` under the data root, keeping the last N copies.
- **S6 — Deployment and host.** Audit: "No hay rotación de logs de Docker", "`bootstrap.sh` solo crea `data/` y `.env`. Falta abrir 443 y 80 en iptables y en la lista de seguridad de OCI, configurar swap, ejecutar `systemctl enable docker` y montar el volumen en fstab", "No hay límites de memoria en compose", "la imagen `web` (Caddy) se ejecuta como root", "`data/` tiene permisos `0700` y pertenece al UID 65532, así que el `rsync` de la entrega necesitará `sudo`". Compose gets log rotation, memory limits and a web healthcheck; web runs non-root; bootstrap provisions the host idempotently; the rsync delivery is documented.
- **S7 — Client robustness.** Audit: "El XHR no tiene `xhr.timeout`", "Los reintentos no tienen jitter", "Si falta la miniatura, la galería carga el original". The upload XHR aborts after a stall and retries; backoff adds jitter; grid tiles never load originals; `503 uploads_paused` shows "Las subidas están en pausa" without retry storms.
- **S8 — Load tests on the A1.** Audit: "`scripts/load` solo sube fotos sintéticas: no prueba vídeo, ancho de banda limitado, Range ni reinicios." Load scripts cover T3 (25 slow video uploads) and T5 (gallery and Range readers in parallel), with a documented measurement procedure for the QA host.
- **S9 — Documentation.** "Por el resto de detalles me parecen estupendos, mientras lo dejes documentado." Runbook, API, data model and ADRs (Spanish) describe every change.

Out of scope (L2): Oracle idle reclamation, volume resize, stable release/rollback pinning — the user prepares them manually on the QA/production host.
